Antes de empezar: derivadas e integrales

Si nunca has visto cálculo, estas dos ideas son la base de todo el libro. Aquí van explicadas desde cero, con un ejemplo resuelto paso a paso.

¿Qué es una derivada?

La derivada mide qué tan rápido cambia algo. Si f(x) es la posición de un carro, su derivada es la velocidad. Gráficamente, es la pendiente (inclinación) de la curva en un punto.

Definición

f′(x) = limh→0 f(x + h) − f(x)h

En palabras: avanzamos un pasito h, medimos cuánto cambió la función y dividimos entre el pasito. Luego hacemos el pasito tan pequeño como queramos (h → 0).

Ejemplo: derivada de f(x) = x² usando la definición

  1. Calculamos f(x + h) = (x + h)² = x² + 2xh + h²
  2. Restamos: f(x + h) − f(x) = 2xh + h²
  3. Dividimos entre h: 2x + h
  4. Hacemos h → 0: f′(x) = 2x

El atajo: regla de la potencia

si f(x) = xⁿ  ⟹  f′(x) = n · xⁿ⁻¹

Se "baja" el exponente a multiplicar y se le resta 1. Por ejemplo:

  1. f(x) = 3x² + 5x
  2. f′(x) = 3·2x + 5·1 = 6x + 5
  3. En x = 2 la pendiente es 6·2 + 5 = 17

¿Y la IA? Una red neuronal aprende calculando derivadas del error: le dicen en qué dirección mover cada parámetro para equivocarse menos. Eso es el descenso de gradiente (Parte I).

¿Qué es una integral?

La integral es la operación inversa de la derivada. También sirve para calcular el área bajo una curva, o sea, para "sumar" infinitos pedacitos muy pequeños.

Integral indefinida (la antiderivada)

∫ xⁿ dx = xⁿ⁺¹n + 1 + C   (n ≠ −1)

Se le suma 1 al exponente y se divide entre el nuevo exponente. La C es una constante, porque al derivar cualquier número da 0.

  1. ∫ (6x + 5) dx = 6·x²2 + 5x + C = 3x² + 5x + C
  2. Comprobación: si derivamos 3x² + 5x volvemos a 6x + 5 ✔

Integral definida (el área)

∫ab f(x) dx = F(b) − F(a)

donde F es la antiderivada de f. Esto es el Teorema Fundamental del Cálculo.

Ejemplo: área bajo x² entre 0 y 2

  1. Antiderivada: F(x) = x³3
  2. Evaluamos arriba: F(2) = 83
  3. Evaluamos abajo: F(0) = 0
  4. Restamos: ∫02 x² dx = 83 ≈ 2.67 unidades de área

¿Y la IA? En probabilidad, el área bajo una curva de densidad es una probabilidad. Las integrales están detrás de los modelos probabilísticos y de la estadística (Parte III).
