Antes de começar: derivadas e integrais

Se você nunca viu cálculo, essas duas ideias são a base de todo o livro. Aqui estão explicadas do zero, com um exemplo resolvido passo a passo.

O que é uma derivada?

A derivada mede quão rápido algo muda. Se f(x) é a posição de um carro, sua derivada é a velocidade. Graficamente, é a inclinação da curva em um ponto.

Definição

f′(x) = limh→0 f(x + h) − f(x)h

Em palavras: damos um passinho h, medimos quanto a função mudou e dividimos pelo passinho. Depois fazemos o passinho tão pequeno quanto quisermos (h → 0).

Exemplo: derivada de f(x) = x² usando a definição

  1. Calculamos f(x + h) = (x + h)² = x² + 2xh + h²
  2. Subtraímos: f(x + h) − f(x) = 2xh + h²
  3. Dividimos por h: 2x + h
  4. Fazemos h → 0: f′(x) = 2x

O atalho: regra da potência

se f(x) = xⁿ  ⟹  f′(x) = n · xⁿ⁻¹

"Desce" o expoente multiplicando e subtrai 1 dele. Por exemplo:

  1. f(x) = 3x² + 5x
  2. f′(x) = 3·2x + 5·1 = 6x + 5
  3. Em x = 2 a inclinação é 6·2 + 5 = 17

E a IA? Uma rede neural aprende calculando derivadas do erro: elas dizem em que direção mover cada parâmetro para errar menos. Isso é a descida de gradiente (Parte I).

O que é uma integral?

A integral é a operação inversa da derivada. Também serve para calcular a área sob uma curva, ou seja, para "somar" infinitos pedacinhos muito pequenos.

Integral indefinida (a antiderivada)

∫ xⁿ dx = xⁿ⁺¹n + 1 + C   (n ≠ −1)

Soma-se 1 ao expoente e divide-se pelo novo expoente. O C é uma constante, porque a derivada de qualquer número é 0.

  1. ∫ (6x + 5) dx = 6·x²2 + 5x + C = 3x² + 5x + C
  2. Verificação: se derivarmos 3x² + 5x voltamos a 6x + 5 ✔

Integral definida (a área)

∫ab f(x) dx = F(b) − F(a)

onde F é a antiderivada de f. Este é o Teorema Fundamental do Cálculo.

Exemplo: área sob x² entre 0 e 2

  1. Antiderivada: F(x) = x³3
  2. Avaliamos em cima: F(2) = 83
  3. Avaliamos embaixo: F(0) = 0
  4. Subtraímos: ∫02 x² dx = 83 ≈ 2.67 unidades de área

E a IA? Em probabilidade, a área sob uma curva de densidade é uma probabilidade. As integrais estão por trás dos modelos probabilísticos e da estatística (Parte III).
